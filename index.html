01 / START HERE

Start with a duplicate theme

Before editing a live storefront, duplicate your current theme in Shopify Admin. Use the duplicate as a safe workspace, then preview every change on desktop and mobile.

Good habit
Keep a note of the file you changed and the original code. It makes rollback easier.
02 / LIQUID BASICS

Understand Liquid output and logic

Double curly braces output values; curly-brace percent tags run logic.

{% if product.available %}
  {{ product.title }}
{% else %}
  Sold out
{% endif %}

Confirm the object exists in the template where you paste the snippet. A variable available on a product page may not exist on a collection page.

03 / INSTALLATION

Add a reusable snippet

  1. Open Online Store → Themes → Edit code.
  2. Under Snippets, add a new snippet.
  3. Name it clearly and paste the Liquid code.
  4. Call it from a supported template with {% render 'your-snippet-name' %}.
  5. Save and preview the duplicate theme.
Note
Some examples are fragments. Add any needed markup, styles, schema or JavaScript before production use.
04 / BEFORE YOU PUBLISH

Test the whole experience

  • Check available and sold-out products.
  • Test variant changes, cart updates and keyboard navigation.
  • Check mobile layout, console errors and theme performance.
  • Confirm compatibility with your theme and current Shopify APIs.
